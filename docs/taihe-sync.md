# 太和剪藏数据线同步

Spark 设置页的「数据线同步到手机」现支持鸿蒙太和剪藏。太和需要 0.4.0 或更新开发版，并在太和剪藏 → Spark 同步中开启开关。连接数据线并允许设备调试后，电脑选择「太和剪藏」即可同步。现有插线自动同步及每 10 分钟同步也适用；同步完成后回到手机剪藏列表接收。

范围仅为本地笔记库 `Spark/剪藏/` 与太和剪藏：正文、图片、摘要、译文、标签、备注及日期。不会调用模型、访问云服务或交换模型密钥。图片使用本地缓存通过数据线传递。

使用内容版本和持久化基线判断单端/双端变更。首次同 URL 内容不同以及双端冲突会保留电脑原稿，把手机内容另存「同步冲突副本」，并向手机发送两个版本。手机在接收期间又编辑了文章时也保留副本。删除和回收站各自保留；未改动的手机条目不自动重建电脑已移除的文件。

HDC 可从 PATH、DevEco Studio 或相邻 Taihe_HMOS 开发工程自动发现。自定义安装可在启动 Spark 前设置 `SPARK_HDC=/absolute/path/to/hdc`。非默认设备服务可设置 `SPARK_HDC_SERVER=127.0.0.1:8710`。HDC 缺失不影响原有苹果设备通道。当前连接要求应用沙箱调试访问，不含发布版非调试连接或网络直接同步。

实现为 `core/taihe_sync.py`，由 `core/cable_sync.py` 的设备发现与同步入口分派；界面沿用现有设置页。状态放在设置目录的 `taihe-sync/<device>/<vault-hash>/`，包含版本基线、未确认包和覆盖前备份。先推正文/图片，最后推 ready；手机校验后保存，并记录接收游标。重复重传和旧包不覆盖新内容。确认后的临时包可清理，正式文章与附件保留。

限制：每篇同步正文 4 MB、每图 8 MB、每篇最多 80 张图。拒绝越界及符号链接路径。电脑和手机保留不同的本地存储布局，不同步其他节目、报告或相册数据。

测试 `tests/test_taihe_sync.py` 覆盖双向、重复、双端冲突、传输中断、附件名转换、删除与冲突映射。2026-11-10 全工程 1242 项测试及 10 个子测试通过。鸿蒙独立测试应用和临时笔记库实际传输 12/12 通过，包括 SHA-256 损坏拒收与重传。测试没有修改真实笔记库。
