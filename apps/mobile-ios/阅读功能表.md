# 阅读功能表

手机阅读页（ReaderShell）上每种文档能做什么。开关定义在 `Spark/ReaderFeatures.swift`（`ReaderFeatures.of`），种类怎么从路径和页签推出来在 `Spark/ReaderPlace.swift`。

`tests/test_reader_features.py` 把开关函数编出来，和这张表逐格比对，不一致就失败。加功能、改开关，必须同时改这张表。

格子是种类本身的开关。实际显示时还有几条按路径或内容收窄（只关不开）：

- 路径不能做笔记（`PathRules.annotatable` 为否）：关掉做笔记和图片重下、删图；文档的星标也关掉（剪藏除外）。
- 改名称、继续追问要 `PathRules.editable`；删除要 `PathRules.canDelete`（复盘只有 `output/复盘/` 下直接的一篇）。
- 单集的星标记在第一份能做笔记的稿子上（`ReaderPlace.starPath`），一份都没有就不显示。
- 语言切换只在内容确实是中英对照稿（`Markdown.isBilingual`）时显示；翻译成中文只在还有没译的段落时显示。
- 原文链接要有网址：单集用处理记录里的网址，剪藏用文件头里的 url。

种类说明。

单集（ReaderView 打开的一期）按页签认：

- 单集小结：播客单集、会议议题、信息里按节目流程处理的一期的「小结」页签，小结文件读到之后。
- 处理记录里的小结：「小结」页签在小结文件读到之前（或者没有小结文件），显示处理记录里的一句话总结和正文。信息文章的文件读不到、或者文件里没有「## 小结」「## 原文」两节时，小结页签也是它。
- 整理稿、文字记录：对应的页签。
- 信息文章（小结）：信息订阅里按文章处理的一期（只有文章文件，没有小结文件和整理稿，`ReaderPlace.splitsArticle`）的「小结」页签，显示文章文件里「## 小结」那一节。文件读到、两节都在（`ReaderPlace.articleSections`）才算。
- 信息文章（原文）：信息订阅里一期的「原文」页签。按文章处理的一期显示文件里「## 原文」那一节；缺一节时显示整个文件（照旧）。

能做笔记的种类里，下面这几处不能划线、批注（只能选字拷贝）：标题、表格、代码块、图片、图注；里面含标题或列表的复杂引用，其中的段落和列表项；提示框的标题行（「> [!note] 标题」）；排版和文件原文对不上的行（例如链接地址里带括号、HTML 实体），划的时候会提示原因。

信息文章的小结、原文两个页签是同一个文件：只挂一份笔记（DocNotes），任一页签上划线、批注、写读后感，两个页签都按新内容重排；读后感卡片两个页签都有。星标、目录里的划线和批注列表按整个文件算；从目录或读书笔记跳到一处划线时，这一页上没有就切到另一页。

文档（DocReaderView 打开的一篇）按路径认，规则在 `ReaderPlace.doc`，按下面的顺序，先认上的算数（路径规则见 `PathRules`）：

1. 剪藏：`Spark/剪藏/` 下直接的一篇 `.md`，`索引.md` 除外。`Spark/剪藏/摘录.md` 和隐藏文件也算剪藏，只是不能做笔记。
2. 随手记：`Spark/笔记/` 下直接的一篇 `.md`，不以「.」开头。`索引.md`、`摘录.md`、`笔记.md` 也算随手记，只是不能做笔记。
3. 复盘：`output/复盘/` 下的 `.md`，包括更深的子文件夹。只有直接的一篇能删；`索引.md` 不能做笔记。
4. 总览页：上面三类以外、不能做笔记的路径（`PathRules.annotatable` 为否）。包括：不在 `Spark/`、`output/` 下的；不是 `.md` 的；路径里有空段或以「.」开头的段的；文件名是 `索引.md`、`摘录.md` 的（比如 `Spark/剪藏/索引.md`）；文件名和所在文件夹同名的（节目 / 会议总结）。
5. 报告：`output/` 下其余的 `.md`，不限层数，比如 `output/<主题>/技术洞察报告_….md`。
6. 简报：`Spark/信息跟进/` 下其余的 `.md`，不限层数，不只是简报，信息文件夹里当文档打开的都算。
7. 会议资料：剩下的 `Spark/` 下的 `.md`。主要是节目、会议文件夹里没有处理记录的文章，也包括 `Spark/剪藏/<子文件夹>/` 这类路径。

## 「没有」的原因

做笔记
- 处理记录里的小结：内容在处理记录里，没有文件可写。
- 总览页：按定义就是不能做笔记的路径；生成的列表页每次重新生成，笔记会被盖掉，笔记库那两个目录以外的、不是 Markdown 的也写不进笔记。

星标
- 总览页：不能做笔记的文档不进书架的「星标」。

改名称
- 信息文章（原文、小结）、单集小结、处理记录里的小结、整理稿、文字记录：标题跟着处理记录走，在电脑上改。
- 简报、报告、会议资料、总览页：标题由生成规则定，手机上不改。
- 随手记：标题在「编辑」里改。

删除
- 信息文章（原文、小结）、单集小结、处理记录里的小结、整理稿、文字记录：一期的几份稿子一起由电脑管，手机上不单删一份。
- 简报、报告、会议资料、总览页：生成的文件由电脑管，手机上不删。

语言切换
- 信息文章（原文、小结）：电脑端已经给信息文章配了译文（原文段后面跟「> 译文」）。手机上目前固定按文件里的样子显示（原文后跟译文引用），语言切换在下一步加。
- 单集小结、处理记录里的小结、文字记录：只有一种语言。
- 简报、报告、复盘、会议资料、随手记、总览页：不出中英对照稿。

翻译成中文
- 信息文章（原文、小结）：译文由电脑端生成，手机上不翻译。
- 除剪藏以外的其余种类：翻译只针对剪藏的「## 正文」一节。

重写摘要
- 除剪藏以外的种类：只有剪藏的摘要在手机上写。

继续追问
- 除复盘以外的种类：追问写进复盘文件，别的文档没有这一节。

编辑随手记
- 除随手记以外的种类：不是自己手写的文字，正文不在手机上改。

没进电脑提示
- 处理记录里的小结：没有文件，不会有手机上的修改。

流量下载确认
- 剪藏、简报、报告、复盘、会议资料、随手记、总览页：文档读不到时只显示出错原因（照旧）。
- 单集小结、处理记录里的小结、信息文章（小结）：小结先显示处理记录里的那份，文件拿不到不报错。

图片重下和删图
- 除剪藏以外的种类：只有剪藏的图片是手机下载的。

文字记录说明条
- 除文字记录以外的种类：说明条只讲语音识别的误差。

未译段数提示
- 剪藏：也有对照稿，但没译完的段落用「更多」里的「翻译成中文」补译，原来就不显示这条提示（照旧）。
- 信息文章（原文、小结）：手机上目前固定按文件里的样子显示，没有语言切换，也就没有这条提示；语言切换在下一步加。
- 其余种类：不出中英对照稿。

处理记录小结
- 除处理记录里的小结以外的种类：它们都显示文件本身。

小结过滤
- 除单集小结以外的种类：只有小结文件末尾有指向别的稿子的链接和旧的「我的高亮」。

剪藏整理
- 除剪藏以外的种类：只有剪藏的正文从网页转来，要整理。

原文链接
- 简报、报告、复盘、会议资料、随手记、总览页：没有单一的原始网址。
